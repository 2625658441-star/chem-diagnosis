# 化学学情诊断平台

作者：黎伟成

## 怎么用

1. **老师端**：打开 `index.html`
   - 打印答题卡 → 学生涂卡
   - 手机拍照识别 或 手工录入成绩
   - 一键导出 Excel（学号 / 姓名 / 分数 / 逐题对错）
   - 生成学生报告二维码，学生扫码回家看详细报告

2. **学生端**：扫描答题卡上的二维码 → 自动打开 `student.html?...`

## 部署到 GitHub Pages

见 `部署指南.md`。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 老师端（单页应用，含题库） |
| `student.html` | 学生端（扫码进入的详细报告） |
| `view.html` | 报告查看器（与 student.html 相同） |

## 数据在哪

所有数据都存在**你自己的浏览器**里（localStorage + IndexedDB），
不会上传到任何服务器。换电脑或清缓存前，请在「学生与记录」页导出备份。
